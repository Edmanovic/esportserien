# ESPASS Security Lab

Automated attack simulations for the secure foundation. These tests are abuse-case oriented and produce reports under `security-lab/reports`.

Initial attack classes:

- Malicious extension messages.
- Replay attacks.
- Malformed envelopes.
- Vault tampering.
- Clipboard interception simulations.
- XSS payload attempts.
- IPC fuzzing.
- Origin spoofing.

Run targets will be wired into CI once local Rust and Node runtimes are installed.
